# liga_futbol.cpp  
Liga de futbol por Angel David Romero Alarcon  

Organiza una liga de futbol como si fueras su dueño (añadiendo los partidos y sus puntos goles,etc)  

El comando para compilarlo es: g++ -o liga src/main.cpp  

Si manejas windows (no creo) es "liga.exe" en tu caso usuario de linux seria (./liga)  

El archivo usa la estructura que ya se vio formato=valor (Ej: gatos=1), uno por línea. Las líneas que empiezan con # son comentarios para que los ignore el programa y sean solo comentarios. Los equipos se agregan repitiendo el "formato=equipo" una vez por cada equipo.
